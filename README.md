# Рахманинов · Прелюдия до-диез минор, соч. 3 № 2 — видео целиком из кода

Вертикальный ролик 1080×1920, 60 к/с, в духе Synthesia, в эстетике рубежа XIX–XX веков: тёмный салон
при лампе, гравюрная штриховка рук, манжеты с запонками и фрак, кремовая слоновая кость и эбен,
золотые (правая рука) и «берлинская лазурь» (левая рука) ноты, которые в перспективе летят на
клавиатуру. Есть и плёночный «синематограф» с зерном, мерцанием, пылью, царапинами, виньеткой и диафрагмой.
Звук рояля тоже синтезирован кодом, без сэмплов.

```bash
npm install
npm run render        # → out/rachmaninoff-prelude-op3-no2.mp4 (~40 мин на 2 vCPU)
node src/main.js --stills 7,80,150          # отдельные кадры в out/stills
node src/main.js --from 120 --to 140 --fps 30  # превью фрагмента
```

Нужны Node ≥ 20 и `ffmpeg` в `PATH`.

## Как это устроено

| Модуль | Что делает |
| --- | --- |
| `src/midi.js` | Разбор MIDI (SMF) без зависимостей |
| `src/score.js` | Нотный текст → исполнение: карта темпа с rubato и «вздохами» перед колоколами, динамика по пометкам партитуры (ppp…sffff, вилки), голосоведение (колокола, тема, мелодия, аккомпанемент) |
| `src/hands.js` | Распределение по рукам и **аппликатура** лучевым поиском по физически возможным позициям кисти (пределы растяжки между пальцами, подкладывание большого пальца, удержание нот). Неберущиеся аккорды раскладываются, как у пианистов: бас чуть раньше доли, затем перескок. Моменты нажатия и отпускания клавиш, ключевые позы кисти |
| `src/pedal.js` | Педаль по гармоническим сменам («запаздывающая» педаль; в Agitato полупедаль, чтобы бас не обрывался) |
| `src/audio/` | Физически мотивированный синтез рояля: негармоничные обертоны, растянутый строй, спектр удара молоточка по скорости, двойное затухание и биения трёх струн хора, демпферы, симпатический резонанс при педали, корпус, концертный зал (FDN-реверберация), мастеринг |
| `src/render/handanim.js` | Кинематика: траектории кисти с минимальным рывком, дуга при перескоках, бросок веса руки в sff-аккордах, поворот предплечья от локтя; пальцы проходят подготовку, удар с ускорением, ведут клавишу вниз и отпускают её. Сочувственные движения соседних пальцев, обратная кинематика фаланг (DIP ≈ ¾ PIP), выбор глубины кисти по досягаемости |
| `src/render/*` | Перспективная камера с упреждающим кадрированием и толчками на sffff; клавиши с реальным ходом (поворот вокруг оси баланса) и индикаторами состояния: нажата (цвет руки, яркость от силы), звучит на педали (затухающее свечение), отпущена; ноты-«слитки» с гравированной рамкой и названием; искры, ударные кольца, угольки, летящие навстречу ♪; лучи света в кульминации; титульная и финальная карточки, лира с педалями |

Звук и изображение строятся из одного и того же списка событий (`buildPerformance()`), поэтому
каждое нажатие клавиши, удар молоточка и смена педали совпадают с точностью до сэмпла и кадра.

  распространяется на тех же условиях; указание авторства есть в финальных титрах.
* Шрифты (`assets/fonts`): Old Standard TT, Pinyon Script и Playfair Display SC,
  все под SIL Open Font License, тексты лицензий лежат рядом.
