# Рахманинов · Прелюдия до-диез минор, соч. 3 № 2 — видео целиком из кода

Вертикальный ролик 1080×1920, 60 к/с, ~1,5 минуты, в духе Synthesia, в эстетике рубежа XIX–XX веков:
тёмный салон при лампе, кремовая слоновая кость и эбен, золотые (правая рука) и «берлинская лазурь»
(левая рука) ноты, которые в перспективе летят на клавиатуру, плёночный «синематограф» с зерном,
мерцанием, пылью и диафрагмой. Руки — объёмные 3-D кисти, отрисованные собственным растеризатором.
Звук рояля тоже синтезирован кодом, без сэмплов.

Сокращённая редакция (такты 1–8 → 28–30 → 35–47 → 54–55 → 62) склеена в местах, где музыка
стыкуется сама: доминанта такта 8 переходит в ff-возвращение Agitato, такт 30 нота в ноту совпадает
с тактом 34, такты 47 и 54 стоят на одном басовом до-диезе, финальный аккорд под ферматой.

```bash
npm install
npm run render        # → out/rachmaninoff-prelude-op3-no2.mp4 (два процесса, ~25 мин на 2 vCPU)
node src/main.js --stills 7,80,150          # отдельные кадры в out/stills
node src/main.js --from 120 --to 140 --fps 30  # превью фрагмента
```

Нужны Node ≥ 20 и `ffmpeg` в `PATH`.

## Как это устроено

| Модуль | Что делает |
| --- | --- |
| `src/midi.js` | Разбор MIDI (SMF) без зависимостей |
| `src/score.js` | Нотный текст → исполнение: карта темпа с rubato и «вздохами» перед колоколами, динамика по пометкам партитуры (ppp…sffff, вилки), голосоведение (колокола, тема, мелодия, аккомпанемент) |
| `src/hands.js` | Распределение по рукам и **аппликатура** лучевым поиском по физически возможным позициям кисти (пределы растяжки между пальцами, подкладывание большого пальца, удержание нот). Неберущиеся аккорды раскладываются, как у пианистов: бас чуть раньше доли, затем перескок. Моменты нажатия и отпускания клавиш, ключевые позы кисти |
| `src/pedal.js` | Педаль по гармоническим сменам («запаздывающая» педаль; в Agitato полупедаль, чтобы бас не обрывался) |
| `src/audio/` | Физически мотивированный синтез рояля: негармоничные обертоны, растянутый строй, спектр удара молоточка по скорости, двойное затухание и биения трёх струн хора, демпферы, симпатический резонанс при педали, корпус, концертный зал (FDN-реверберация), мастеринг |
| `src/render/handanim.js` | Кинематика рук. Для каждого аккорда поза кисти находится оптимизацией анатомического удобства (естественные углы суставов, разведение пальцев, высота костяшек, линия предплечья). Между аккордами кисть движется по гладкой C¹-траектории, стоит на месте, пока звучит аккорд, делает дугообразные перескоки и «бросает вес» в громких аккордах. Длинные пальцы управляются в пространстве суставов (подъём вращением в костяшке, DIP ≈ ⅔ PIP), касание решается обратной кинематикой; у большого пальца своя цепь с противопоставлением. Палец отпускает клавишу, если кисть ушла и он не дотягивается (звук держит педаль) |
| `src/render/handmesh.js` | Процедурная анатомическая сетка кисти (ладонь с костяшками, перепонка большого пальца, фаланги с утолщениями суставов, растворяющееся предплечье), перестраиваемая каждый кадр. Программный растеризатор с z-буфером и сглаживанием 2×2, попиксельный шейдинг кожи (рассеяние света в коже, ногти с лункой, складки на суставах, сухожилия и вены, контровой свет), мягкие швы и гравюрный контур, тень на клавишах |
| `tools/` | Метрики естественности рук (`handstats.mjs`), крупные планы (`closeup.mjs`), серии кадров (`seq.mjs`), профайлер |
| `src/render/*` | Перспективная камера с упреждающим кадрированием и толчками на sffff; клавиши с реальным ходом (поворот вокруг оси баланса) и индикаторами состояния: нажата (цвет руки, яркость от силы), звучит на педали (затухающее свечение), отпущена; ноты-«слитки» с гравированной рамкой и названием; искры, ударные кольца, угольки, ♪; лучи света в кульминации; титр поверх сцены, финальная карточка, лира с педалями |

Звук и изображение строятся из одного и того же списка событий (`buildPerformance()`), поэтому
каждое нажатие клавиши, удар молоточка и смена педали совпадают с точностью до сэмпла и кадра.
